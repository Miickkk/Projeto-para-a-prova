# Calculadoras de Saúde

Desafio de prático para React + Material UI (MUI).

## Funcionalidades
- Calculadora de IMC com classificação.
- Calculadora de água diária pela fórmula peso × 35ml.
- Histórico dos cálculos.
- Navegação global.

## Rotas
- `/` — Calculadora de IMC.
- `/agua` — Calculadora de água diária.
- `/historico` — Histórico salvo no navegador.
